# twigg-agent

An alias for [`@twigg/agent`](https://www.npmjs.com/package/@twigg/agent), so that
`npx twigg-agent` works. It installs and runs the same version of `@twigg/agent`, and nothing
else.

```sh
npx twigg-agent task.md --model claude-sonnet-5
```

Documentation: https://github.com/Twigg-AI-Ltd/twigg-agent
